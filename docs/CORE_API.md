# PARKLY core — API notes for screen builders

Files: `src/data.js` (window.PARKLY_DATA), `src/engine.js` (window.PARKLY), `src/core.css`, `build.py`, `src/_smoke.html` (model markup for pass, bill, heat, ring; include markers).

## window.PARKLY
Objects: `D` (data), `S`, `A`, `Router`, `SvgMap`, `QR`, `Dial`, `Illus`, `fmt`; consts `HOUR`, `MIN`, `TIMES`, `STORE_KEY`.

Store: `S.state`; `S.set(fn|partial, reason)` (persists to localStorage `parkly.proto.v1`); `S.subscribe(fn(state, reason, prev))` → unsubscribe. Reasons: tick, booking, demo, reset, seed, alerts, notify.

Actions `A.*` returning `{ok, value|error}`: `createBooking({facilityId, vehicleId, start, end, mode, requirements[], notes, promo, method})`, `modifyBooking(id,{start,end,mode,vehicleId,requirements})`→{diff}, `previewModify(id,o)` (live diff, no save), `extendBooking(id,min)`, `cancelBooking(id)`, `toggleCompare(fid)` (max 3), `upsertVehicle(v)` (validates plate), `removeVehicle(id)`.
Returning values: `quoteExtension(id,min)`→{ok,issues[],newEnd,price,extra,free}; `refundPreview(id)`→{amount,percent,note,paid}; `exitPreview(id)`→{overMs,fee}; `checkAlerts()`→count; `jumpToNextEvent()`→label|null.
Other: `completeOnboarding(guest)`, `signOut`, `setUser`, `setPrefs`, `setNotify`; `setSearch({start,end,mode,sort,…})`, `setFilters`, `resetFilters`, `setDestination(id)`, `setCustomDestination({name,lat,lng})`, `nearMe()`, `viewed(fid)`, `setSavedPlace`; `toggleSaved`, `clearCompare`, `setDefaultVehicle`; `markArrived(id)`, `markExited(id,fee)`; `notify(n)`, `markRead`, `markAllRead`, `removeNotification`, `clearNotifications`; `saveSearch(label,alerts)`, `toggleSearchAlert`, `removeSearch`, `runSavedSearch(sid)`; `refreshAvailability`, `setDemo(p)`, `setClockOffset(min)`, `advanceClock(min)`, `resetDemo()`.

Engine functions (on PARKLY): time `now()`, `at(dateKey,timeKey)`, `dateKey`, `timeKey`, `ceilHalfHour`, `startOfDay`, `addDays`, `defaultWindow`; lookups `facility(id)`, `destination(id)`, `defaultVehicle()`, `getBooking(id)`, `unreadCount()`, `searchCenter(search)`; money `money`, `rateFor(f,vt)`, `dailyFor`, `applyPromo(code,parking,startMs)`, `quote({facility,start,end,mode,vehicleType,evCharging,promo})`→{…,total,lines[]}, `refundPreview(b,f,nowMs,pending)`, `policyPercent`, `cancelDeadline(b,f)`→{at,percentNow,percentAfter}, `overstayFee(f,vt,overMs)`, `paidSoFar(b)`; distance `distKm`, `walkMin`, `mapsUrl(p,mode)`; availability `availability(f,s,e,bookings,seed,excludeId)`→{free,fullSlot}, `hourlyAvailability(f,dayStart,bookings,seed)`, `isOpenAt`, `hoursLabel`, `availTone(free,cap)`→ok|low|none, `toneClass`; checks `validateBooking({facility,start,end,mode,vehicle,bookings,seed,nowMs,excludeId})`→{issues[{field,message}],free}, `bookingStatus(b)`, `isOverstay`, `statusTone`, `genRef`, `genBay`, `validPlate`, `normPlate`, `calendarLinks(b,f)`→{google,ics}, `downloadFile(name,text,type)`; search `searchFacilities({search?,bookings?,seed?,vehicleType?,center?})`→{results:[{f,km,walk,free,rate,total,score,reason}],total}, `rankResults`, `sortCompare`, `activeFilters(filters)`→[{key,label,clear}], `matchesType`, `buildSeedState(ms)`.

HTML helpers (return strings): `icon(name,size,cls)` (80 lucide icons), `esc`, `logo(size,word)`, `plate(p,'sm'|'lg')`, `occ(free,cap)`, `stars(r,count,{row})`, `badge(text,tone,icon)`, `statusBadge(b)`, `bill(quote)`, `ring(frac,{size,stroke,tone,html})`, `amenityIcons(f)`.
DOM helpers: `h(html)`→element, `$`, `$$`, `rollNumber(el,text)`, `toast(text,tone,{label,onClick},ms)`, `openSheet({title,body,footer,size,kind:'auto'})`→{el,body,footer,close} (bottom sheet on body.m, modal on body.d; Esc/backdrop/[data-close] close it; Router closes sheets on route change), `closeTopSheet()`, `confirmDialog({title,body,confirm,tone,cancel})`→Promise<bool>, `reducedMotion()`, `runTick()`, `applyPrefs()`.
`fmt`: money, time12, timeLabel, dateLabel, dayLabel, windowLabel, durationLabel, durationShort, countdown, ago, kmLabel, dateKey, timeKey, numLabel.

Map: give the element a height; `const m = SvgMap.render(el,{items: searchFacilities().results, dest: searchCenter(S.state.search), radiusKm, selectedId, routeTo:f, compact, onSelect, onSearchArea, onOpen, onPinHover})`; then `m.update({...})`, `m.select(id)`, `m.highlight(id)`, `m.recenter()`, `m.destroy()`. `compact:true` = static thumbnail calling `onOpen` on tap.
Dial: `Dial.mount(el,{valueMin,minMin,maxMin,stepMin,startMs,onChange,label,prefix:'+',sub:min=>html})`→{get,set,update,destroy}.
Router: `Router.on(fn(route,prev))`, `Router.start()`; route = {name,params,query,path}; names per PLAN §3, `#/` = landing; `Router.go('/reserve/khan',{start:…})`, `Router.back()`, `Router.replace()`.
Tick: every 15 s adds "Starts soon"/"ends in 15 minutes" notifications + toast. Seed starts `onboarded:false`. `A.setDemo({nextPaymentFails:true})` is handled by the checkout screen. Prefs set `html[data-text=large]` / `[data-motion=reduce]`.

## Shells (core.css)
Mobile: `body.m > .stage > .device > (.statusbar, main.screen[data-scroll-root] > .topbar + .page + .actionbar, nav.tabbar > a.tab > .tab-ico)`; ≥520px = 390×844 phone frame, below = full screen; `.device.no-tabbar`; `.floating` (compare tray); `.stage-note`; put `fmt.timeLabel(now())` into `.sb-time`.
Desktop: `body.d > .app > aside.sidebar (.sidebar-logo, .nav > .nav-item.is-on, .nav-badge, .sidebar-foot) + main.main > .page`; `.dtop` sticky 72px top bar; `.split` (420px rail + map); `.two-col`; `.sticky-col`; `.grid-2/3/4`; `.app.no-sidebar` for landing.
